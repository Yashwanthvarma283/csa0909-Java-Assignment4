# Task 5 - Currency Converter

## Files

- Converter.java
- ConverterA.java
- ConverterB.java
- ConverterC.java

## How to compile and run

```
javac Converter.java ConverterA.java ConverterB.java ConverterC.java
java Converter
java ConverterA
java ConverterB
java ConverterC
```

## Result

- Converter: lambda listener, the button and the Enter key both convert.
- ConverterA: the frame implements ActionListener.
- ConverterB: named inner class.
- ConverterC: anonymous inner class.

An invalid amount shows Invalid amount.
